# Full research execution placement

This fork policy owns only the placement of Full mode's Related Docs Finder.
Classification and the body draft remain in the controller's conversation.
It does not select Lightweight mode or remove Full mode's overlap search,
session-history probe, grounding validation, vocabulary work, or report.

Honor applicable user, caller, and project execution assignments before choosing
placement. Check `.ce-orca.json` in the project when present; a selected profile
or caller execution patch is also an assignment. Resolve configured execution
through `references/orca-routing.md` and retain the existing dispatch path.
Do not silently replace an assigned model or requested independent research
with the parent. Invalid or unreadable configuration follows the routing error
path.

Otherwise, use **local research** when the current conversation contains the
solved problem, its explanation, and verification evidence, and the defining
code and related learning corpus can be inspected within the remaining context.
Use **delegated research** when reconstructing missing evidence or searching the
corpus needs separate substantial investigations. When coverage is uncertain,
retain delegated research. A short conversation alone is not evidence that the
problem is solved.

Announce the selected placement and its reason. On the local path, read the rest
of `references/research.md` and perform its setup and the finder contract in
the parent alongside classification and drafting. Inspect the current tree and search the learning corpus afresh;
session familiarity does not replace either check. Produce the same
`related.json` artifact in the run directory,
using the existing complete-inline-output fallback if an artifact cannot be
written. Do not enter the subagent dispatch instructions or create a research
packet on this path. Assembly still waits for classification, the body draft,
the finder result, and the Full mode session-history flow.

Return to Full mode's session-history step after the local finder output exists.
Later phases keep their existing activation and independence requirements;
local research does not satisfy a separate grounding validator. If investigation
outgrows the context, retain useful source evidence and enter the existing
finder dispatch before assembly. Delegated research keeps the upstream finder
contract; classification and drafting never cross that dispatch boundary.

In the existing completion report, identify local or delegated Phase 1 research
and the actual delegated research-worker count. Report later delegates separately so a
local research pass is never described as an entirely subagent-free Full run.
